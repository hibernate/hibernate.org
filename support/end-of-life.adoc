= End-of-Life Support
:awestruct-layout: support-standard

The link:/support/maintenance-policy[maintenance] of Hibernate projects focuses on the latest series.

When a series reaches end-of-life, it is no longer maintained and thus will no longer receive fixes for bugs or even vulnerabilities.

Application developers temporarily unable to upgrade from end-of-life'd versions of Hibernate projects
but still requiring fixes for security vulnerabilities
should look for end-of-life support.
